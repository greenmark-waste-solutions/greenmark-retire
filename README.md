# Greenmark Retire

Registry of Greenmark repositories that have been retired, archived, or cleaned up.

This repo documents:
- **What** was retired
- **When** it was retired
- **Why** it was retired
- **What archived it or superseded it** (if applicable)

## Purpose

Maintain an audit trail for decommissioned infrastructure, products, and documentation. Prevents re-discovery of dead code and clarifies historical decisions.
